# 🌿 WellnessHub AI

> A modern wellness tracking web application designed to help users understand and improve their daily wellness habits.

## 🚀 About the Project

WellnessHub AI is a web-based wellness tracker that allows users to record their daily habits and receive personalized wellness insights.

The application focuses on simple, practical tracking of hydration, sleep, physical activity, and mood while presenting progress through scores, trends, and achievements.

## ✨ Features

- 💧 Daily water intake tracking
- 😴 Sleep tracking
- 🏃 Physical activity tracking
- 😊 Mood tracking
- 📊 Personalized wellness score
- 🤖 AI-inspired wellness insights
- 📈 7-day wellness trend
- 🏆 Achievement badges
- 🌙 Dark mode
- 💾 LocalStorage-based data persistence
- 📱 Responsive user interface

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript
- Browser LocalStorage
- Git & GitHub
- GitHub Pages

## 🎯 Project Goal

The goal of WellnessHub AI is to create a simple and engaging digital wellness companion that encourages users to build healthier daily habits through tracking, visualization, and personalized feedback.
